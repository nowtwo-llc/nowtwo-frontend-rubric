frontendrubric

A rubric editor for the browser. Criteria, weighted grading scales, standards alignment and drag-to-reorder — rendered as form inputs inside your own form, with no save of its own.

  • v9.0.0
  • TypeScript
  • 1 dependency
  • MIT

Try it

Drag a row by its grip to reorder it. Type in a point value and the scale re-sorts around it without losing your place. "Add standard" opens a stand-in for the host's standards picker.

What gets posted

This editor has no save button. It writes named inputs into the surrounding form and the host submits them, so the field names are a contract with your server. Press Show form data above to see exactly what the form would send.

Install

npm install @nowtwo-llc/frontend-rubric

Use

import { RubricEditor } from '@nowtwo-llc/frontend-rubric';
import '@nowtwo-llc/frontend-rubric/style.css';

const editor = new RubricEditor({
    container: '#nt-rubric-app',
    criteria: window._criteria
});

editor.mount();

Read the live rubric back with editor.criteria and the running score with editor.totalPoints. Call destroy() to remove the DOM and every listener it registered.

Host integration

Everything page-specific goes through one HostBridge: icon markup, tooltip attributes, activation, opening the standards picker and dismissing tooltips. The default implementation reads a window.RubricHost object of that shape, which is exactly what this page defines in host.js — the whole reason the demo can run the real bundle with no application framework behind it.

  • HE:StandardsTool:SelectStandard — the picker chose a standard
  • HE:StandardsTool:RemoveStandard — the picker cleared one

Both are dispatched on document by the host, and both event names are configurable.
